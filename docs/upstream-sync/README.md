## 分支与仓库角色

- `upstream`：权威上游 `https://github.com/MddIdd/mdd-sim-gateway.git`。
- `origin`：自有仓库 `https://github.com/suyi-92/mdd-sim-gateway.git`。
- `main`：权威上游镜像；定制功能持续保留在 `vmware`。
- `codex/vmware-sync-vX.Y.Z`：一次上游同步的隔离集成分支；普通合并完成后将结果快进交付给 `vmware`。
- `origin/vmware`：本独立仓库的正式交付分支，也是受管更新获取的分支；不涉及父项目或 gitlink。
